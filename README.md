## Web prototype

Production URL:

https://sharp-jsljmfjqv-jhyunkns-projects.vercel.app

## Test on phone with Expo Go

1. Install **Expo Go** from the iPhone App Store.
2. Clone or download this repository.
3. From the project folder, run:

```bash
npm install
npm run start
```

4. A QR code will appear in the terminal or browser.
5. Open the iPhone Camera app or Expo Go and scan the QR code.
6. Sharp will open inside Expo Go.

This Expo version is a lightweight native shell around the live Vercel app, so design/content changes deployed to Vercel are immediately visible in the phone test shell.
